Что показывать на месте «Связаться» для общественных Дог-парков?

Для потеряшек и компаньонов телефон необходим. Но для публичных площадок звонить некому. Выберите логику:

A. Замена на «Поделиться» (Share)

🔗 Поделиться
B. Одна широкая кнопка (Single Wide Route)

Дог-парк Центральный (Площадка)

C. Замена на «В избранное» (Favorite)

A

Замена на «Поделиться» (Share)

Для площадок вторая кнопка превращается в «Поделиться» (копирует ссылку на дог-парк). Для животных остается «Связаться».

B

Одна широкая кнопка (Single Wide Route)

Для площадок показываем только одну большую кнопку маршрута на всю ширину. Для животных — две кнопки.

C

Замена на «В избранное» (Favorite)

Для площадок вторая кнопка становится «В избранное» (добавляет место в закладки владельца). Для животных остается звонок.
