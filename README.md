# 🐾 PawConnect — Apple Liquid Glass Pet Companion App

**PawConnect** — кроссплатформенное мобильное и веб-приложение на **Flutter 3.x** с премиальным дизайном **Apple Liquid Glass** (темный обсидиан `#0A0A0C`, стеклянные карточки `#1C1C1E`, полупрозрачные оверлеи `BackdropFilter`).

Репозиторий: `https://github.com/dimdimych96/pawconnect_flutter.git`

---

## ⚡ Принципы разработки (Production Architecture)

1. **Реальный API и отсутствие скрытых заглушек (Zero-Stub Policy)**:
   - Сетевые сервисы (`lib/services/`) работают с реальным бэкендом на FastAPI.
   - Ошибки сети, авторизации (401/403) и валидации явно обрабатываются и выводятся пользователю, без скрытого подсовывания моков.
2. **Яндекс Карты на `flutter_map`**:
   - Картографический движок `flutter_map` + `latlong2` с тайлами **Яндекс Карт** (`https://core-renderer-tiles.maps.yandex.net/tiles...`).
   - Настройка ночных и кастомных тем через GPU-шейдер `ColorFilter.matrix` (`MapThemeProvider`).
   - Маркеры являются нативными Flutter виджетами (`Marker(child: Widget)`).
3. **Реальная Авторизация**:
   - JWT Bearer токены, безопасное хранилище `FlutterSecureStorage` и автоматический перехват 401 через `AuthInterceptor`.
4. **Бюджет производительности Liquid Glass**:
   - Размытие `BackdropFilter` строго ограничено плавающими панелями навигации и шторками; в элементах скроллящихся списков используются быстрые полупрозрачные заливки.

## 📲 Вкладки и Возможности Приложения

1. 💬 **Лента Instagram 2026 (`/feed`, Главная вкладка)**:
   - Stories-лента питомцев района вверху экрана.
   - Посты с фотографиями, категориями (`Здоровье`, `Дрессировка`, `SOS`) и фильтром по 10 районам Новосибирска.
   - Анимированные лайки Heart Pop и комментарии.
2. 🗺 **Интерактивные Яндекс Карты (`/map`)**:
   - Пульсирующий маркер ошейника с анимированной аурой.
   - Безопасная геозона (радиус 50–500м) и трек прогулок питомца.
   - Метки дог-парков, компаньонов и SOS-потеряшек.
   - Полноценная OSRM-маршрутизация (пешком, безопасный путь через парки, авто).
3. 🔍 **Поиск и Discovery (`/search`)**:
   - Полноэкранный поиск мест, клиник, площадок и объявлений с фильтрами по категориям и радиусу.
4. 🐾 **Паспорт питомца и Ошейник (`/profile`)**:
   - Аватар собаки, порода, чип, телеметрия батареи ошейника.
   - Настройка радиуса геозоны с шагом ±10м.
   - Вет-календарь процедур и прививок.
5. ⚙️ **Настройки (`/settings`) & Глобальный Аларм**:
   - Профиль владельца, пуши, панель диагностики бэкенда.
   - Глобальный красный стеклянный аларм-баннер тревоги вверху любого экрана при побеге из геозоны.

## 🚀 Быстрый Запуск Проекта

### Требования
- Flutter SDK 3.x+ (Dart 3.x+)
- Браузер Google Chrome / Эмулятор Android / iOS Simulator

### Инструкция по запуску:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/dimdimych96/pawconnect_flutter.git

# 2. Перейти в папку проекта
cd pawconnect_flutter

# 3. Установить зависимости
flutter pub get

# 4. Запустить приложение (в Chrome веб-версии)
flutter run -d chrome

# Или запустить на локальном веб-сервере (localhost:8080)
flutter run -d web-server --web-port 8080
```

## 🔄 Гайд: Работа над проектом с разных устройств (Quick Sync)

Схема быстрой синхронизации изменений между несколькими ПК / устройствами.

### 💻 Сценарий A: Завершение работы на Устройстве №1 (Сохранение)

Перед тем как отойти от компьютера №1, закоммитьте и отправьте все изменения на GitHub:

```bash
# 1. Проверить измененные файлы
git status

# 2. Зафиксировать все изменения
git add .
git commit -m "feat: добавлена логика вет-календаря и геозоны"

# 3. Отправить на GitHub
git push origin main
```

---

### 💻 Сценарий B: Начало работы на Устройстве №2 (Получение)

Когда вы садитесь за второй ПК:

#### 1️⃣ Если проект запускается на этом ПК впервые:
```bash
git clone https://github.com/dimdimych96/pawconnect_flutter.git
cd pawconnect_flutter
flutter pub get
flutter run -d chrome
```

#### 2️⃣ Если проект уже был склонирован ранее (Обновление свежего кода):
```bash
# Подтянуть последние изменения с GitHub
git pull origin main

# Обновить зависимости (если добавлялись новые пакеты)
flutter pub get

# Запустить приложение
flutter run -d chrome
```
